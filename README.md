# ReActPractice
Student Academic Support Agent - ReAct-based AI agent that helps students access academic information and manage assignments.
The agent dynamically decides which function to call based on the student’s question. After receiving each tool result, it continues the reasoning loop until it can provide a final response.
Key Features
Student profile lookup
Assignment status checking
Overdue assignment detection
Tool calling with the OpenAI API
Multi-step ReAct reasoning loop
JSON-based tool responses
Final student-friendly summaries
